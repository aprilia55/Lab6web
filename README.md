**📊 Penjelasan Hasil Praktikum 6: Twitter Bootstrap**

Pada praktikum ini, hasil yang diperoleh menunjukkan bahwa Bootstrap sangat membantu dalam membuat tampilan web menjadi lebih cepat, rapi, dan responsif tanpa harus menulis banyak kode CSS secara manual.

***🔹 1. Hasil Setup Bootstrap***

Bootstrap berhasil diintegrasikan ke halaman web menggunakan CDN.
Setelah link Bootstrap ditambahkan, tampilan tombol dan teks langsung berubah menjadi gaya bawaan Bootstrap tanpa tambahan CSS khusus.

***🔹 2. Hasil Container dan Grid System***

Penggunaan `container` dan `row` dengan `col` membuat tata letak halaman menjadi teratur dan mudah disusun.
Tampilan tiga kolom pada layout dapat menyesuaikan ukuran layar secara otomatis (responsive).
Artinya, di layar kecil kolom akan menumpuk ke bawah, dan di layar besar tersusun sejajar ke samping.

***🔹 3. Hasil Komponen Button dan Navbar****

Tombol `btn` berhasil tampil dengan berbagai warna sesuai class (`primary`, `success`, danger, `dll`).

Navbar tampil di bagian atas halaman dengan warna gelap (bg-dark) dan dapat collapse (menjadi menu hamburger) saat ukuran layar diperkecil — menunjukkan bahwa fitur responsive navigation dari Bootstrap bekerja dengan baik.

***🔹 4. Hasil Komponen Card***

Komponen .`card` berhasil menampilkan kotak berisi gambar, judul, dan teks yang sudah memiliki gaya otomatis dari `Bootstrap`.
Card ini juga bisa digunakan untuk menggantikan tampilan widget atau box pada layout sebelumnya di Praktikum 4.

***🔹 5. Hasil Komponen Form***

Form yang dibuat menggunakan `class` .form-control dan .`form-label` terlihat lebih rapi dan konsisten, dengan jarak antar-elemen yang otomatis proporsional.
Tampilan form menjadi profesional tanpa harus menulis CSS tambahan.

***🔹 6. Hasil Halaman Portfolio***

File portfolio.html berhasil menampilkan:

Navbar di bagian atas halaman.

Bagian `“Tentang Saya”` dengan foto di kolom kiri dan deskripsi diri di kolom kanan.

Bagian `“Portfolio Saya”` dengan 3 kolom card yang masing-masing berisi gambar dan teks proyek.
Semua elemen tersusun rapi dan tetap responsif di berbagai ukuran layar.
